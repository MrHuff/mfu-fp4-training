# Final public training histories

These CSVs contain the complete numerical histories used by the training-loss
figures for TE NVFP4 with four final BF16 blocks and the operand-wise
fixed-H32 hybrid. Each has 3,815 literal observations from step 1 through
logged step 38,140. The endpoint comparison contains only scientific scalar
values.

Private run identities, service locations, timestamps, checkpoint inventories,
and operational receipts are deliberately absent. Exact checkpoint and source
provenance remains in the separately sealed evidence repository.
